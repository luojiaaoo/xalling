# 命令说明

在输入框中以 `/` 开头即可使用斜杠命令。输入 `/` 后会自动弹出可用命令与技能的列表，用方向键选中后按回车发送。

---

## /compact — 压缩上下文

**作用**：总结到目前为止的对话内容，释放上下文空间（token），让长会话可以继续进行。

**用法**：

```
/compact
/compact 重点保留数据库迁移相关的讨论
```

**参数**：可选，自定义总结指令。告诉模型压缩时重点保留哪些内容，其余内容会被更激进地省略。

**使用场景**：会话变长、响应变慢或提示上下文不足时使用。建议在每个任务阶段完成后主动压缩一次。

---

## /init — 生成项目说明文件

**作用**：分析当前项目的代码库结构，生成一份 `CLAUDE.md` 项目说明文件。之后每次会话都会自动读取它，让模型快速理解项目。

**用法**：

```
/init
```

**参数**：无。

**使用场景**：第一次在新项目中使用时执行一次即可。生成后可以手动编辑 `CLAUDE.md`，补充项目特有的约定和注意事项。

---

## /recap — 会话摘要

**作用**：立即生成当前会话的一行摘要（recap），方便快速回顾这个会话在做什么。

**用法**：

```
/recap
```

**参数**：无。

---

## /reload-skills — 重新加载技能

**作用**：让当前会话立即识别磁盘上新增或修改过的技能（skills），无需重启会话。

**用法**：

```
/reload-skills
```

**参数**：无。

**使用场景**：刚刚安装、新建或编辑了技能文件（如 `~/.claude/skills/` 下的内容）后，执行一次即可在当前会话中使用新技能。

---

## /verify — 端到端验证改动

**作用**：通过实际运行受影响的功能来验证代码改动是否真的生效——驱动真实流程并观察行为，而不只是跑测试或类型检查。

**用法**：

```
/verify
```

**参数**：无。

**使用场景**：提交任何非琐碎的改动之前使用。注意：只改了测试、文档等没有可运行表面的代码时不需要用它，因为没有可观察的行为。

---

## /code-review — 代码审查

**作用**：审查当前的代码改动（或指定的 PR / 分支 / 路径），找出正确性 bug 以及可复用、可简化、效率方面的问题。

**用法**：

```
/code-review
/code-review high
/code-review 123
/code-review medium --fix
/code-review max --comment src/utils/
```

**参数**：

| 参数 | 说明 |
| ---- | ---- |
| `low` / `medium` | 审查力度较低，只报告高置信度的问题 |
| `high` / `xhigh` / `max` | 审查力度更高，覆盖面更广，可能包含不确定的发现 |
| `--fix` | 审查完成后直接把修复应用到工作区 |
| `--comment` | 把审查结果作为行内评论发布到 PR |
| `<pr#>` / `<branch>` / `<path>` | 指定审查目标：PR 编号、分支名或文件路径；不填则审查当前未提交的改动 |

不填力度时会沿用上次使用的力度。

**使用场景**：提交代码前自查，或审查他人的 PR。`/code-review --fix` 可以一键完成"审查 + 修复"。

---

## /security-review — 安全审查

**作用**：对当前分支上待提交的改动做一次完整的安全审查，发现注入、越权、敏感信息泄露等安全隐患。

**用法**：

```
/security-review
```

**参数**：无。

**使用场景**：涉及鉴权、数据处理、外部输入的改动，提交前建议跑一次。

---

## /team-onboarding — 团队上手指南

**作用**：根据你的实际使用记录，为团队新成员生成一份 Claude Code 上手指南，帮助同事快速入门。

**用法**：

```
/team-onboarding
```

**参数**：无。

**使用场景**：团队里有人刚开始使用 Claude Code 时，用它生成一份贴合你们实际用法的教程。

---

## /dataviz — 数据可视化

**作用**：在生成任何图表、仪表盘或数据可视化之前加载的可视化规范，保证产出的图表美观、规范、风格统一。支持 HTML、SVG、matplotlib、plotly、d3、Recharts 等各种输出形式。

**用法**：

```
/dataviz 把这份销售数据做成趋势图
```

**参数**：在命令后直接用自然语言描述你要做的图表即可。

**使用场景**：画图表、做仪表盘、可视化数据之前。直接提"图表""可视化""dashboard"等需求时模型也会自动加载它。

---

## 技能

技能同样以 `/` 开头调用，列表中带有技能标识的条目即为技能。技能由 Claude 运行时提供，会随项目和插件配置动态变化，例如本项目中的飞书系列技能（`/lark-doc`、`/lark-sheets` 等）。

## 提示

- 命令选中后如需参数，直接在命令后面补充再发送。
- 命令执行过程中可以随时点击停止按钮中断。
