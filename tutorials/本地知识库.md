# 本地知识库

侧栏“知识库”只读展示已入库文件的父目录和原路径，操作后可点击刷新。所有工作区共享一套资料，不需要人工分类。

在对话中告诉 AI：“把 `docs/ESP32开发手册.pdf` 导入知识库。”应用直接读取原路径，只保存索引和元数据，不复制、上传或改写原文档。

搜索时可以这样说：

- “在知识库中搜索开发板识别失败的排查方法。”
- “只在 `D:/资料/嵌入式` 及其子目录中搜索串口连接失败。”
- “同时搜索 `D:/资料/嵌入式` 和 `E:/项目/硬件`，引用来源路径和片段编号。”
- “全局搜索固件烧录。”
- “列出 `D:/资料` 里已入库、文件名含 ESP32 的文件。”

AI 使用关键词和本地正文向量进行混合搜索，融合两路结果，支持自然语言问题及中英文关键词；也可以按文件名列出已入库文件。正文搜索支持同时指定多个父目录，包含其所有子目录，重叠范围会去重；不指定目录就是全局搜索。你明确指定目录时，AI 会保持该范围。首次导入或搜索会下载本地中文嵌入模型，之后可离线使用，文档不上传。

支持 Office、OpenDocument、RTF、EPUB、CSV、文字型 PDF、UTF-8 TXT/Markdown；单文件最大 200 MiB。扫描 PDF 需先在本地完成 OCR。相对路径以当前会话项目为基准，也支持绝对路径和 `~`。

知识库以 JSON 清单为准并原子保存，记录尚未完成的索引写入。搜索前只检查文件修改时间和待建标记：已完成且时间未变的文件直接跳过，不读取向量做校验；更新或上次未完成的文件重新写入。写入失败会在下次搜索重试。

删除文件记录时先删除向量，再更新 JSON；新增时先保存 JSON，再生成向量。向量写入失败后保留 JSON，下一次搜索自动重建。所有文件操作按原路径识别和覆盖。

每次正文搜索前，应用会检查全库所有已入库文件的修改时间，包括搜索范围之外的文件。修改时间变化时，先删除旧正文和向量索引，再从原路径重新导入；未变化时只检查时间，不重读正文。原文件删除或移动后，旧路径会同步移出知识库，新路径需另行导入。同步失败时会报错，不返回过期内容，下次搜索继续重试。文件以绝对路径标识，不同路径分别入库，同名或相同内容的文件也各自保存。如果修改内容时保留了原修改时间，需先更新文件修改时间。正文及元数据保存在 `.xalling/xalling-knowledge/`，本地模型保存在 `.xalling/xalling-embedding-models/`。旧版纯关键词索引需要备份并移走知识库目录后重新导入，以建立正文向量。
